# Pond（池塘）

蛙灾的 Blender 工具箱。N 面板「池塘」页，四个抽屉。

仅支持 **Blender 5.2**。

> 池塘曾与上游项目在 [上游项目](https://example.invalid/upstream)
> 合并维护过一段时间；本仓库是从合体版拆出的纯池塘，共享的核心逻辑
>（快照、拎出等）随拆分一并带出。

## 功能清单

| 抽屉 | 模块 |
|---|---|
| 🧹 整理 | 父子级（所选打组/单个拎出/全部拎出/选父级）、原点吸附（顶/底/左/右四向）、一键拆分（按松散块拆开） |
| 🔨 制作 | 六面投射、图转立体（位图轮廓挤出）、预设库（几何节点/材质，库路径偏好可配，存入即标记资产可注册为资产库）、烘焙贴图、色卡（图片提取调色板 + 悬浮色卡窗）、C4D 互导（分组FBX/Alembic/材质清单/Empty还原集合） |
| 💡 灯渲 | 明度检查（白膜AO/黑白显像）、视图渲染同步（视图可见性 vs 渲染开关一致性）、视窗渲染对比（截屏快照 + 分割线 A/B 对比）、灯光台（标签分组 + solo + 一键同步 Cycles 灯光组）、分层渲染（一键通道EXR） |
| 🎞 动画 | 摄像机组 |

**视窗渲染对比**：快照池全局共用，拍摄自动找「渲染」着色模式的视口，
对比只画在渲染视口（双视口工作流为设计基准）。拍摄走整窗截屏裁切，
视图变换（ACES/Filmic）所见即所得，Cycles/EEVEE 通吃；
列表点选即切换，删除正在显示的自动跳下一张。

### 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl + Alt + 右键` | 拍快照 |
| 左键按住分割线拖动 | 拖动快照分割线（线两侧 8px 内生效） |
| `Alt + 右键`（拖动） | 拖动快照分割线（任意位置） |

## 安装 / 开发

**仓库根目录即插件包根目录**——把整个仓库文件夹复制/链接到 Blender 的
`scripts/addons/` 下（文件夹名保持 `pond`）即可启用；打 zip 直接压缩仓库根目录。

```
pond/                 # 仓库根 = 插件包根
├── __init__.py       # bl_info + 注册中心（prefs → core → ui）
├── prefs.py          # AddonPreferences（模块开关 + 预设库路径）
├── core/             # 逻辑层：全部 Operator/PropertyGroup，无 Panel
├── ui/pond/          # 池塘 UI（sections 四抽屉 + panels 各模块子面板）
└── tools/            # 诊断脚本（Blender 内运行）
```

## 已知问题

1. 快照拍摄为「所见即所得」：渲染未采样安定时拍摄会存下当前进度的噪点图；
   视口上开着的叠加物（网格线/gizmo）会一起入镜。
2. 灯光组同步仅 Cycles 支持（EEVEE 无灯光组机制，分灯层请用分层渲染多跑几遍）。
