# Pond（池塘）🐸

蛙灾的 Blender 工具箱。N 面板「池塘」页，四个抽屉，做动画短片的日常都在这。

仅支持 **Blender 5.2**。

## 安装

把整个仓库文件夹放进（或链接到）Blender 的 `scripts/addons/` 下，
文件夹名保持 `pond`，偏好设置里启用即可；打 zip 直接压缩仓库根目录再「从磁盘安装」。

用不到的模块可以在 偏好设置 → 插件 → Pond 里逐个关掉，面板就不显示了。

## 🧹 整理

**父子级**
- 所选打组：其他所选物体挂到激活物体下面，世界位置不动
- 单个拎出：只把自己摘出来，孩子交还给上一级（层级不断链）
- 全部拎出：连同整个子树一起拔出来，回到场景根
- 选择所有父级：一键选中所选物体的直接父级

**原点吸附**
所选物体的原点批量吸到包围盒的 顶部 / 底部 / 左部(−X) / 右部(+X) 面中心。
「底部」吸完把 Z 归零就正好落地，摆场景神器。

**一键拆分**
把一个网格按松散块（不相连的部分）拆成多个独立物体。
可选「先按距离焊点」（防止本该相连的碎面被拆散）和「拆完原点各自居中」。

## 🔨 制作

**六面投射**：从六个正交方向往物体上投贴图，快速给形体上概念色。

**图转立体**：位图轮廓自动描边并挤出成网格，logo / 剪影图一键变立体。

**预设库**
自己养的几何节点 / 材质预设库。激活物体上的节点组或材质一键入库
（起名 + 备注），列表选中一键挂到所有选中物体。
- 库路径在面板顶部或偏好设置里改，每个预设是独立 .blend，跨工程通用
- 存入时自动标记为资产；点路径旁的小按钮可把库注册为 Blender 资产库，
  在资产浏览器里也能看到自己的预设（带预览图），两种用法随意切换

**烘焙贴图**：程序化材质烘成贴图，支持烘完一键切换 原始/烘焙 材质对照。

**色卡**：从图片提取调色板，可开悬浮色卡窗一边建模一边取色。

**C4D 互导**：按组导出 FBX / Alembic、生成材质清单、Empty 还原集合结构，
和 C4D 那边来回倒文件用。

## 💡 灯渲

**明度检查**
两种一键检查视图，再按一次还原：
- 白膜(AO)：材质全覆盖成白膜+环境光遮蔽，纯看形体和光影（Cycles）
- 黑白显像：按人眼亮度权重转灰（不是简单去色），检查画面明度关系

**视图渲染同步**
渲染前必查：把「视图里看得见/看不见」和「渲染开关」不一致的
物体、集合、修改器全部揪出来，按集合分组列出。
「全部：以渲染为准」= 渲染开关不动、改视图；「以视图为准」反之；
组头小按钮只对齐那一组。对齐错了 Ctrl+Z 直接撤。

**视窗渲染对比**
Octane Live Viewer 那种 A/B 对比，改灯改材质前先存一张，改完拉线对比：
- `Ctrl+Alt+右键` 拍快照（自动找「渲染」着色模式的视口，
  从别的视口按也不会拍错；对比画面也只出现在渲染视口）
- 拍的是屏幕最终像素，视图变换（ACES/Filmic）、曝光所见即所得，
  Cycles/EEVEE 通吃；渲染没采样安定时拍会存下当前进度
- 分割线**左键按住直接拖**（`Alt+右键` 拖也行），左实时右快照
- 列表点哪条显示哪条；删除正在显示的自动跳下一张；
  快照存在显存里，重开文件后列表自动清空

**灯光台**
场景里的灯（和真正的发光材质网格）自动进台，自建标签组管理：
- 每盏灯 / 每组：solo（可叠加）、视口藏显，都只动视图可见性不碰渲染开关
- 分组默认收起，点开的组会话内记住
- 「同步为 Cycles 灯光组」：灯光台的分组一键写成 Cycles Light Groups，
  渲染一次 EXR 里每组灯一个通道，后期单独调亮度颜色不用重渲
  （仅 Cycles；EEVEE 没有灯光组机制，分灯层请用分层渲染多跑几遍）

**分层渲染（一键通道EXR）**
一键打开常用渲染通道（漫射/光泽/透射三件套、体积、自发光、环境、AO、
雾场、Cryptomatte×3、阴影捕捉、降噪配套），并在合成器自动接好
「渲染层 → 多层EXR文件输出」，每个通道一条线，灯光组通道也自动接上。
输出路径默认取渲染输出路径，在文件输出节点上改。
「拆掉通道EXR」一键还原（只删节点，通道开关保留）。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl + Alt + 右键` | 拍快照 |
| 左键按住分割线拖 | 拖快照分割线（线两侧 8px 内生效） |
| `Alt + 右键` 拖 | 拖快照分割线（任意位置） |

## 已知脾气

1. 快照是「所见即所得」：视口开着的叠加物（网格线/gizmo）会一起入镜，
   渲染视口平时把叠加层关了就干净
2. 灯光台判定发光材质看「发光强度 × 发光颜色」都非零，只调过强度
   没给颜色的材质不会被误收
